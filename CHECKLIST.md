# ЧЕК-ЛИСТ проверки (перед каждым деплоем)

## Критические правила (из опыта)

### 1. bot.py — всегда py_compile
```bash
python3 -c "import py_compile; py_compile.compile('bot.py', doraise=True)"
```

### 2. Главы — всегда verify.py (36/36)
```bash
cd /mnt/agents/output/book && python3 verify.py
```

### 3. Картинки — проверить img/ перед деплоем
```bash
ls deploy/img/*.jpg | wc -l   # должно быть 6+ картинок
ls deploy/stories/*/img/*.jpg  # картинки глав тоже на месте
```
- ✅ Генерируем в `book/stories/XX/img/` → копируем в `deploy/stories/XX/img/`
- ❌ Не копировать → пропадут при следующем деплое

### 4. Формат \n — буквальные 2 символа
- ✅ `\\n` в HTML/JS (два символа: \ + n)
- ❌ Реальный перенос строки (0x0A) — ломает JS

### 5. Не удалять deploy/ полностью
- ✅ `cp -r` — копировать поверх
- ❌ `rm -rf deploy/` — теряются файлы

### 6. Отступы в Python
- ✅ 4 пробела
- ❌ Табы / смешанные отступы

### Где появились затыки
| Этап | Проблема | Причина |
|------|----------|---------|
| Шаг 1/5 `/preview` — генерация | Зависание на 6+ минут | `subprocess.run()` блокирует asyncio event loop PTB v21 |
| Шаг 2-5 | Не доходили | Бот не отвечал пока ffmpeg работал |
| `/debug` — диагностика | Тоже молчала | `sys` не импортирован внутри функции (NameError) |
| `/approve` — публикация | Не тестировалось | preview не доходил до этого шага |
| `aiohttp` для HTTP вызова | Render не деплоил | Возможно конфликт зависимостей |
| `run_in_executor` — async fix | Не помогло | `.result()` блокировал, `await` не подхватывался Render |

### Почему subprocess ломает PTB v21
- PTB v21 использует `asyncio` для обработки update'ов
- `subprocess.run()` — синхронный вызов, блокирует event loop
- Бот не может отвечать пока ffmpeg кодирует видео (20-30 сек)
- Все остальные пользователи тоже зависают
