```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  AI Генерация │ -> │  Selenium    │ -> │  TikTok     │
│  (видео + текст)│    │  (браузер)   │    │  (автопост) │
└─────────────┘    └──────────────┘    └─────────────┘
                            │
                            v
                     ┌──────────────┐
                     │  Instagram   │

                     └──────────────┘
                            │
                            v
                     ┌──────────────┐
                     │  Telegram    │
                     │  (автопост)  │
                     └──────────────┘
```

### Технологии:
| Компонент | Как работает |
|-----------|-------------|
| Видео | AI generate_video (бесплатно) |
| Текст | Я пишу цитаты и описания |
| TikTok | Selenium Chrome (вход, загрузка, публикация) |
| Instagram | Selenium Chrome или Meta API |
| Telegram | Bot API (python-telegram-bot) |
| Расписание | Cron (запуск каждый день в 9:00) |
