# Живая Книга — навигация по проекту

Читай в начале каждой сессии.

## Что это за проект

**Живая Книга** — интерактивная эротическая платформа для женщин. Каждая история — ветвящийся сюжет, где читательница выбирает путь героини. Слоган: *«Каждый выбор — твоя история»*.

## Структура репозитория

## Система Идей (NEW)

### Как это работает
1. **Ты пишешь:** `идея:` + описание (тезисы, описания, мысли)
2. **Я сохраняю:** в `ideas/XXX-title.md` с номером и датой
3. **Я использую:** подтягиваю подходящие идеи при написании сценариев
4. **Формат:** свободный — тезисы, описания, образы

## Правила работы

1. **Каждый выбор = уникальная ветка.** Нет одинаковых путей.
2. **Стиль "ты"** — пишем от второго лица.
3. **Перечитка перед деплоем** — орфография, тире, дефисы.
4. **Картинки под текст** — AI-генерация, 16:9.
5. **Читалка — чистый JS** — никаких фреймворков.
