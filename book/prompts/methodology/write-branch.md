# Написать ветку сценария

## Правило золотое
> **Каждый выбор (choice) ведёт на уникальную сцену с развитием.**

Нет одинаковых путей. Сцены могут сходиться, но путь уникален.

## Алгоритм

1. **Определи точку ветвления** — где читательница выбирает
2. **Для каждого варианта** — напиши уникальную сцену:
   - Реакция персонажа отличается
   - Диалог отличается
   - Эмоциональный тон отличается
   - Развитие сюжета отличается
3. **Сцены могут сходиться** — но только после уникального пути
4. **Картинка соответствует тексту** — что описано, то на изображении

## Шаблон сцены

```javascript
'scene_KEY': {
  location: 'Локация', time: 'Время',
  text: `Текст сцены...
  
Диалоги через — тире.
Прямая речь в «кавычках».`,
  img: './img/filename.jpg', // или URL
  choices: [
    { text: 'Вариант А', next: 'scene_next_a' },
    { text: 'Вариант Б', next: 'scene_next_b' },
  ]
}
```

## Чек-лист качества

- [ ] Каждый выбор ведёт на уникальную сцену?
- [ ] Диалоги отличаются по тону для разных веток?
- [ ] Картинка соответствует тексту?
- [ ] Переходы органичны?
- [ ] Нет обрывов сюжета?

## Пример хорошей ветки

**Плохо:** 3 варианта → одна сцена (игнорировали выбор)
**Хорошо:** 3 варианта → 3 уникальные сцены → сходятся к следующей точке
