# Telegram-бот Живой Книги

Бот: [@Jivaya_kniga_bot](https://t.me/Jivaya_kniga_bot)

## Быстрый старт

```bash
# 1. Установи зависимости
pip install -r requirements.txt

# 2. Создай .env файл
cp .env.example .env

# 3. Запусти
python bot.py
```

Бот запустится и начнёт получать сообщения.

## Команды

| Команда | Описание |
|---|---|
| `/start` | Приветствие + меню |
| `/read` | Ссылка на читалку |
