# Запуск бота на iPhone (через iSH)

## Шаг 1: Установить iSH

1. Открой **App Store**
2. В поиске набери: `iSH`
3. Найди приложение с иконкой альпийской горы (бесплатное)
4. Нажми **ЗАГРУЗИТЬ** (облачко со стрелкой)
5. Дождись установки, нажми **ОТКРЫТЬ**

## Шаг 2: Установить Python

В открывшемся терминале (чёрный экран с буквами) поочерёдно вставляй команды. 

**Как вставить:** долгое нажатие на экран → всплывёт меню → **Paste** (Вставить)

```
apk add python3 py3-pip git
```

Нажми **Return** (Enter на клавиатуре, кнопка внизу справа).

Жди — скачается Python (2-3 минуты).

## Шаг 3: Скопировать код бота

Вставь команду:

```
git clone https://github.com/agafonovdm142-crypto/Book.git
```

Нажми **Return**. Жди — скачается (1-2 минуты).

## Шаг 4: Установить библиотеки

Вставь команду:

```
cd Book/book/telegram-bot && pip3 install -r requirements.txt
```

Нажми **Return**. Жди установки (3-5 минут).

## Шаг 5: Запустить бота

Вставь команду:

```
BOT_TOKEN=8712020124:AAF_Ze10P7gd9rQktUX09PKYuqsalLnGNWs python3 bot.py
```

Нажми **Return**.

Если увидел:
```
Bot started!
```

— бот работает!

## Шаг 6: Проверить

1. Открой Telegram
2. Найди: `@Jivaya_kniga_bot`
3. Нажми **START** или отправь `/start`
4. Должно появиться меню с кнопками

## Важно

- **Не закрывай iSH** — бот выключится. Сворачивать можно (двойной тап Home).
- Если случайно закрыл — повтори **Шаг 5**.
- Чтобы остановить бота — напиши `stop` в терминале.

## Альтернатива (если iSH не работает)

Зайди на сайт **render.com** через Safari:
1. Зарегистрируйся через GitHub
2. Нажми **New** → **Web Service**
3. Выбери репозиторий `Book`
4. В поле **Start Command** напиши: `cd book/telegram-bot && python bot.py`
5. Нажми **Deploy**

Бот будет работать 24/7 без твоего телефона.
