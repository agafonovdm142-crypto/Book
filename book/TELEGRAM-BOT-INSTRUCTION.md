# Инструкция: Создание Telegram-бота для Живой Книги

## Зачем нужен бот

- Читательницы открывают истории прямо в Telegram
- Уведомления о новых главах
- Сбор подписчиков (база для монетизации)
- Автоматическая рассылка

---

## Шаг 1: Создать бота через @BotFather

1. **Открой Telegram** и найди `@BotFather`
   - В поиске сверху набери: `BotFather`
   - Нажми на официальный аккаунт (с галочкой)
   - Нажми **START** или отправь `/start`

2. **Создай нового бота:**
   - Отправь команду: `/newbot`
   - BotFather спросит имя — введи: `Живая Книга`
   - Потом username — введи: `jivaya_kniga_bot`
     (должно заканчиваться на `_bot`, если занято — пробуй `jivayakniga_bot`, `zhivaya_kniga_bot`)

3. **Получи токен:**
   - BotFather отправит сообщение с токеном:
   ```
   Use this token to access the HTTP API:
   123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
   - **Скопируй токен полностью** — он нужен мне
   - **Храни в секрете** — кто угодно с токеном управляет ботом

---

## Шаг 2: Настроить бота

1. **Описание** — отправь BotFather:
   ```
   /setdescription
   ```
   Выбери своего бота, потом текст:
   ```
   Интерактивные эротические истории для женщин.
   Каждый выбор — твоя история.
   Читай бесплатную главу "Субботнее утро" прямо сейчас.
   ```

2. **About (инфо)** — `/setabouttext`:
   ```
   Живая Книга — платформа интерактивных историй для женщин.
   Новые главы каждую неделю.
   ```

3. **Аватарка** — `/setuserpic`:
   - Загрузи квадратную картинку 512x512
   - Могу сгенерировать — скажи

4. **Команды** — `/setcommands`:
   ```
   start - Начать
   read - Читать истории
   chapters - Все главы
   subscribe - Подписаться
   ```

## Шаг 4: Проверить

1. Найди своего бота в Telegram (по username)
2. Нажми START
3. Должно появиться меню с кнопками:
   - Читать "Субботнее утро"
   - Все главы
   - Подписаться
