# Живая Книга — навигация по проекту

Читай в начале каждой сессии.

## Что это за проект

**Живая Книга** — интерактивная эротическая платформа для женщин. Каждая история — ветвящийся сюжет, где читательница выбирает путь героини. Слоган: *«Каждый выбор — твоя история»*.

## Структура репозитория

```
book/
├── CLAUDE.md              ← этот файл, навигация
├── .business/             ← бизнес-контекст (в .gitignore)
│   ├── INDEX.md           ← входная точка
│   ├── audience/          ← аватар, сегменты, путь читателя
│   ├── goals/             ← год / квартал / месяц / неделя
│   ├── economics/         ← unit-экономика, выручка
│   ├── marketing/         ← каналы, воронка, контент
│   └── assets/            ← бренд, гайдлайны
├── plans/                 ← технические планы (1 файл = 1 функция)
├── prompts/               ← готовые промпты (INDEX.md)
├── reader-app/            ← читалка (HTML/CSS/JS)
│   └── img/               ← AI-изображения
├── scenarios/             ← сценарии глав (.md)
├── marketing/             ← стратегия запуска
├── landing/               ← лендинг
├── automation/            ← скрипты авто-постинга
└── retrospectives/        ← рефлексия после сессий
```

## Правила работы (из Scripti)

1. **Один план = одна функция.** Не смешивать.
2. **Каждый выбор = уникальная ветка.** Нет одинаковых путей.
3. **"10 причин обосраться"** — перед каждым деплоем.
4. **Критика плана через 3 субагента** — техника, бизнес, UX.
5. **Retrospective после каждой сессии** — что сделано, что не сделано, уроки.
6. **Прежде чем писать промпт с нуля — загляни в prompts/INDEX.**
