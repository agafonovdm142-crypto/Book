# Аналитика | Живая Книга

## Запрос: счётчик просмотров, время, скролл, лайки

## Анализ возможностей

### Для статического сайта (без бэкенда):

| Функция | Решение | Сложность |
|---------|---------|-----------|
| Счётчик просмотров | Yandex.Metrika или Google Analytics 4 | Низкая |
| Время удержания | Metrika/GA — автоматически | Низкая |
| Скорость пролистывания | Scroll-tracking через JS | Средняя |
| Лайки | LocalStorage (локально) / Firebase (глобально) | Средняя |
| Какие выборы делают | GA4 Events + Firebase | Средняя |

### Проблема статического хостинга

Kimi Pages = статика. Нет PHP, Node, базы данных.

**Решение: Firebase (бесплатный план)**
- Analytics: безлимитно, realtime
- Database: 50K чтений/день — достаточно
- Хостинг: не нужен (уже есть Kimi)

### Два уровня реализации

**Уровень 1 — Сейчас (бесплатно, 30 мин)**
- Yandex.Metrika: визиты, время, глубина прокрутки
- LocalStorage: лайки, прогресс чтения, прочитанные главы
- JS: отслеживание выборов через dataLayer

**Уровень 2 — Потом (Firebase, 2 часа)**
- Глобальные лайки (видны всем)
- Realtime analytics: какие выборы популярны
- Воронка: от входа до финала
- Тепловые карты кликов

## Что внедряю сейчас (Уровень 1)

### 1. Yandex.Metrika
- Визиты, уникальные посетители
- Среднее время на странице
- Глубина прокрутки (scroll depth)
- Клики по кнопкам выбора

### 2. LocalStorage (локальная аналитика читателя)
- Лайк главы (сердечко)
- Прогресс чтения (сколько сцен прочитано)
- Прочитанные главы (галочки на обложке)
- Время начала и конца чтения

### 3. Визуальные элементы
- Кнопка лайка (❤️) в каждой главе
- Прогресс-бар чтения (уже есть, улучшу)
- На обложке: "Прочитано ✓" для завершённых глав
- В конце главы: "Вам понравилась глава? ❤️"

## Что потом (Уровень 2)

При 1000+ читателях:
- Firebase проект
- Глобальные лайки
- Рейтинг глав
- Популярные выборы
- A/B тестирование текстов
