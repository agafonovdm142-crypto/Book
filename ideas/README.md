# Система сбора идей | Живая Книга

## Как это работает

1. **Ты пишешь:** `идея:` + описание (короткие тезисы, описания, мысли)
2. **Я сохраняю:** в папку `ideas/` с номером и датой
3. **Я использую:** подтягиваю подходящие идеи при написании сценариев
4. **Формат идей:** свободный — тезисы, описания, ссылки, образы

## Формат файла идей

Каждая идея — файл `ideas/XXX-title.md`:

```
# Идея XXX: [Название]
- **Дата:** YYYY-MM-DD
- **Источник:** @username
- **Статус:** new | in-progress | used | archived

## Тезисы
- [тезис 1]
- [тезис 2]

## Описание
[развёрнутое описание]

## Где использовать
- [глава/персонаж/сцена]
```
