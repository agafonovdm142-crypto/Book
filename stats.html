API для разработчиков

Счётчики работают через countapi.xyz — бесплатно и без регистрации.

Формат URL: https://api.countapi.xyz/get/zhivaya-kniga/{chapter}_{metric}

Где chapter = 01..06, metric = views | liked | completed

Пример: https://api.countapi.xyz/get/zhivaya-kniga/01_views
