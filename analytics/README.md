# Analytics | Живая Книга

## Доступ к статистике

### Способ 1: Дашборд (веб)
- **URL:** `https://kt7ussahgizfm.kimi.page/stats.html`
- Таблица со всеми метриками
- Обновляется автоматически каждую минуту
- Не требует пароля (данные агрегированные и анонимные)

### Способ 2: Telegram-бот (запаролен)
- **Бот:** `@Jivaya_kniga_bot`
- **Команда:** `/stats`
- **Пароль:** `211114` (только ты)
- Показывает: просмотры, лайки, дочитавшие по каждой главе

### Способ 3: API напрямую
- **Base URL:** `https://api.countapi.xyz/get/zhivaya-kniga/`
- **Формат:** `{chapter}_{metric}`
- **Chapter:** 01, 02, 03, 04, 05, 06
- **Metric:** `views`, `liked`, `completed`
- **Пример:** `https://api.countapi.xyz/get/zhivaya-kniga/01_views`

## Метрики

| Метрика | Описание | Когда считается |
|---------|----------|----------------|
| `views` | Просмотры главы | При каждом новом заходе (1 раз за сессию) |
| `liked` | Лайки | При нажатии ❤️ в главе |
| `completed` | Дочитали до конца | При достижении финальной сцены |

## Что видит читатель

- ❤️/🤍 кнопка в каждой главе
- Прогресс чтения: "Прогресс: 5 сцен"
- ✓ на обложке для прочитанных глав
- ↳ на обложке для начатых глав
- Сводка: "Прочитано: 2/6"
- Cookie consent баннер

## Технологии

- **CountAPI** — глобальные счётчики (бесплатно, без регистрации)
- **LocalStorage** — личный прогресс читателя
- **sessionStorage** — отслеживание сессий (1 просмотр = 1 сессия)
- **analytics.js** — единый модуль для всех глав
